# 105_从前序与中序遍历序列构造二叉树

## 题目

给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的 **先序遍历**， `inorder` 是同一棵树的 **中序遍历**，请构造二叉树并返回其根节点。

**示例 1：**

```
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出：[3,9,20,null,null,15,7]
```

**示例 2：**

```
输入：preorder = [-1], inorder = [-1]
输出：[-1]
```

**提示：**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均 **无重复** 元素
- `inorder` 均出现在 `preorder`
- `preorder` 保证 为二叉树的前序遍历序列
- `inorder` 保证 为二叉树的中序遍历序列

## 解法-分治加哈希定位根节点

先序序列的第一个元素就是根；在中序序列中找到该元素的位置，其左侧为左子树的中序、右侧为右子树的中序，由左子树的长度可切分出对应的先序区间。用哈希表预先记录每个值在中序中的下标，可 O(1) 定位根节点，然后递归构造左右子树。

```C++
class Solution {
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        unordered_map<int, int> index;
        for (int i = 0; i < (int)inorder.size(); ++i) {
            index[inorder[i]] = i;
        }
        return build(preorder, index, 0, (int)preorder.size() - 1,
                     0, (int)inorder.size() - 1);
    }

private:
    TreeNode* build(vector<int>& preorder, unordered_map<int, int>& index,
                    int preLeft, int preRight, int inLeft, int inRight) {
        if (preLeft > preRight) return nullptr;

        int rootVal = preorder[preLeft];
        int mid = index[rootVal];
        int leftSize = mid - inLeft;

        TreeNode* root = new TreeNode(rootVal);
        root->left = build(preorder, index, preLeft + 1, preLeft + leftSize,
                           inLeft, mid - 1);
        root->right = build(preorder, index, preLeft + leftSize + 1, preRight,
                            mid + 1, inRight);
        return root;
    }
};
```

- 时间复杂度：O(n)，建哈希表 O(n)，每个节点构造一次
- 空间复杂度：O(n)，哈希表与递归栈均为 O(n)
