# 114_二叉树展开为链表

## 题目

给你二叉树的根结点 `root` ，请你将它展开为一个单链表：

- 展开后的单链表应该同样使用 `TreeNode` ，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null` 。
- 展开后的单链表应该与二叉树 **先序遍历** 顺序相同。

**示例 1：**

```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [0]
输出：[0]
```

**提示：**

- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

## 解法-寻找前驱节点原地展开

对每个节点，若存在左子树，则先序序列中左子树最后访问的节点（即左子树最右下的节点）正好是右子树的前驱。把它与当前节点的右子树接上，再把左子树整体挪到右边、左指针置空，当前节点的右链就变成先序顺序。之后继续处理新的右孩子，即可原地完成展开，无需额外空间。

```C++
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* cur = root;
        while (cur != nullptr) {
            if (cur->left != nullptr) {
                // 找到左子树中最右侧的节点（先序中 cur 的前驱）
                TreeNode* pre = cur->left;
                while (pre->right != nullptr) pre = pre->right;
                pre->right = cur->right;
                cur->right = cur->left;
                cur->left = nullptr;
            }
            cur = cur->right;
        }
    }
};
```

- 时间复杂度：O(n)，每条边最多被遍历常数次
- 空间复杂度：O(1)，只使用常数个指针
