# 226_翻转二叉树

## 题目

给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

**示例 1：**

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

**示例 2：**

```
输入：root = [2,1,3]
输出：[2,3,1]
```

**示例 3：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中节点数目范围在 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 解法-递归交换左右子树

翻转整棵树等价于：先递归翻转左子树和右子树，再交换根节点的左右孩子。对每个节点都这样处理，整棵树镜像后依然满足要求，因此结果正确。

```C++
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        TreeNode* left = invertTree(root->left);
        TreeNode* right = invertTree(root->right);
        root->left = right;
        root->right = left;
        return root;
    }
};
```

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈深度最坏为 n
