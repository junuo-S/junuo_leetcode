# 230_二叉搜索树中第K小的元素

## 题目

给定一个二叉搜索树的根节点 `root` ，和一个整数 `k` ，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

**示例 1：**

```
输入：root = [3,1,4,null,2], k = 1
输出：1
```

**示例 2：**

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
```

**提示：**

- 树中的节点数为 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

## 解法-中序遍历计数

二叉搜索树的中序遍历结果是严格升序序列，因此中序遍历时对访问到的节点计数，第 k 个被访问的节点值就是第 k 小的元素。用栈迭代实现，找到后可以立即返回，无需遍历完整棵树。

```C++
class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        stack<TreeNode*> st;
        TreeNode* cur = root;
        while (cur != nullptr || !st.empty()) {
            while (cur != nullptr) {
                st.push(cur);
                cur = cur->left;
            }
            cur = st.top();
            st.pop();
            if (--k == 0) return cur->val;
            cur = cur->right;
        }
        return -1;
    }
};
```

- 时间复杂度：O(h + k)，其中 h 为树的高度，最多访问 h + k 个节点
- 空间复杂度：O(h)，栈中最多保存树高个节点
