# 437_路径总和III

## 题目

给定一个二叉树的根节点 `root` ，和一个整数 `targetSum` ，求该二叉树里节点值之和等于 `targetSum` 的 **路径** 的数目。

**路径** 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

**示例 1：**

```
输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：和等于 8 的路径有 3 条。
```

**示例 2：**

```
输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：3
```

**提示：**

- 二叉树的节点个数的范围是 `[0,1000]`
- `-10^9 <= Node.val <= 10^9`
- `-1000 <= targetSum <= 1000`

## 解法-前缀和加哈希表

从根到当前节点的路径和记为 `cur`，若存在某个祖先节点的前缀和等于 `cur - targetSum`，则这两者之间的那段向下路径和恰为 `targetSum`。用哈希表记录当前递归路径上各前缀和出现的次数（回溯时撤销），一次遍历即可统计出所有满足条件的路径数。

```C++
class Solution {
public:
    int pathSum(TreeNode* root, int targetSum) {
        unordered_map<long long, int> prefix;
        prefix[0] = 1;  // 空前缀，便于统计从根节点开始的路径
        return dfs(root, 0, targetSum, prefix);
    }

private:
    int dfs(TreeNode* node, long long cur, int targetSum,
            unordered_map<long long, int>& prefix) {
        if (node == nullptr) return 0;

        cur += node->val;
        int ans = 0;
        auto it = prefix.find(cur - targetSum);
        if (it != prefix.end()) ans += it->second;

        ++prefix[cur];
        ans += dfs(node->left, cur, targetSum, prefix);
        ans += dfs(node->right, cur, targetSum, prefix);
        --prefix[cur];

        return ans;
    }
};
```

- 时间复杂度：O(n)，每个节点只访问一次，哈希表操作为 O(1)
- 空间复杂度：O(n)，哈希表与递归栈的规模均不超过节点数
