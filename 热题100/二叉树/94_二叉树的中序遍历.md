# 94_二叉树的中序遍历

## 题目

给定一个二叉树的根节点 `root` ，返回它的 **中序** 遍历。

**示例 1：**

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [1]
输出：[1]
```

**提示：**

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 解法-递归中序遍历

中序遍历的顺序是「左子树 → 根节点 → 右子树」，按此顺序递归访问并在访问根节点时记录答案，即可恰好按中序输出所有节点。

```C++
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> res;
        dfs(root, res);
        return res;
    }

private:
    void dfs(TreeNode* node, vector<int>& res) {
        if (node == nullptr) return;
        dfs(node->left, res);
        res.push_back(node->val);
        dfs(node->right, res);
    }
};
```

- 时间复杂度：O(n)，其中 n 为二叉树节点数，每个节点访问一次
- 空间复杂度：O(n)，递归调用栈的深度最坏为 n
