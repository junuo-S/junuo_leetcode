# 32_最长有效括号

## 题目

给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

**示例 1：**

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**

```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**

```
输入：s = ""
输出：0
```

**提示：**

- 0 <= s.length <= 3 * 10^4
- s[i] 为 '(' 或 ')'

## 解法-动态规划

设 dp[i] 表示以 s[i] 结尾的最长有效括号子串长度。若 s[i] 为 ')'，当前一个字符为 '(' 时 dp[i] = dp[i-2] + 2；否则若 s[i - dp[i-1] - 1] 为 '('，则 dp[i] = dp[i-1] + 2 + dp[i - dp[i-1] - 2]。前者处理 "...()" 的情况，后者处理 "()(())" 这类嵌套并连接前面有效段的情况，取所有 dp[i] 的最大值即为答案。

```C++
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.size();
        vector<int> dp(n, 0);
        int ans = 0;
        for (int i = 1; i < n; ++i) {
            if (s[i] == ')') {
                if (s[i - 1] == '(') {
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else if (i - dp[i - 1] - 1 >= 0 && s[i - dp[i - 1] - 1] == '(') {
                    dp[i] = dp[i - 1] + 2;
                    if (i - dp[i - 1] - 2 >= 0) {
                        dp[i] += dp[i - dp[i - 1] - 2];
                    }
                }
                ans = max(ans, dp[i]);
            }
        }
        return ans;
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)
