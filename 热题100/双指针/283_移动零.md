# 283_移动零

## 题目

给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意，必须在不复制数组的情况下原地对数组进行操作。

**示例 1：**

```
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]
```

**示例 2：**

```
输入：nums = [0]
输出：[0]
```

**提示：**

- 1 <= nums.length <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1

## 解法-双指针

用 slow 指向下一个应放置非零元素的位置，fast 从左到右扫描数组。遇到非零元素就与 nums[slow] 交换并令 slow 后移，这样非零元素保持原相对顺序，所有零最终都被交换到末尾。

```C++
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.size(); ++fast) {
            if (nums[fast] != 0) {
                swap(nums[slow], nums[fast]);
                ++slow;
            }
        }
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)
