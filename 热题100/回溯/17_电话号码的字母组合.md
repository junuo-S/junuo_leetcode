# 17_电话号码的字母组合

## 题目

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）：`2 -> abc`，`3 -> def`，`4 -> ghi`，`5 -> jkl`，`6 -> mno`，`7 -> pqrs`，`8 -> tuv`，`9 -> wxyz`。注意 `1` 不对应任何字母。

**示例 1：**

```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**示例 2：**

```
输入：digits = "2"
输出：["a","b","c"]
```

**提示：**

- `1 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字。

## 解法-回溯

先保存每个数字对应的字母串，然后按 `digits` 的每一位递归枚举可选字母。当处理完所有数字时，当前路径就是一个完整组合；每个数字位置独立选择，因此所有组合都会被不重不漏地生成。

```C++
class Solution {
    const vector<string> table = {"", "", "abc", "def", "ghi", "jkl",
                                  "mno", "pqrs", "tuv", "wxyz"};

    void dfs(const string& digits, int pos, string& path,
             vector<string>& ans) {
        if (pos == (int)digits.size()) {
            ans.push_back(path);
            return;
        }

        for (char ch : table[digits[pos] - '0']) {
            path.push_back(ch);
            dfs(digits, pos + 1, path, ans);
            path.pop_back();
        }
    }

public:
    vector<string> letterCombinations(string digits) {
        vector<string> ans;
        if (digits.empty()) return ans;

        string path;
        dfs(digits, 0, path, ans);
        return ans;
    }
};
```

- 时间复杂度：O(3^m × 4^k)，其中 m 为映射到 3 个字母的数字个数，k 为映射到 4 个字母的数字个数
- 空间复杂度：O(m + k)，递归栈和当前路径的最大深度
