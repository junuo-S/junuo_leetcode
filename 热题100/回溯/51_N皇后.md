# 51_N皇后

## 题目

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**示例 1：**

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：[["Q"]]
```

**提示：**

- `1 <= n <= 9`

## 解法-按行回溯

逐行放置皇后，因此行冲突天然不存在；再用三个布尔数组分别记录列、主对角线和副对角线是否已被占用。每行尝试所有列，只选择三个方向都不冲突的位置，递归到下一行；放满 n 行就得到一种合法方案，回溯时撤销选择。

```C++
class Solution {
    int n;
    vector<bool> col, diag1, diag2;
    vector<string> board;
    vector<vector<string>> ans;

    void dfs(int row) {
        if (row == n) {
            ans.push_back(board);
            return;
        }

        for (int c = 0; c < n; ++c) {
            int d1 = row - c + n - 1;
            int d2 = row + c;
            if (col[c] || diag1[d1] || diag2[d2]) continue;

            col[c] = diag1[d1] = diag2[d2] = true;
            board[row][c] = 'Q';
            dfs(row + 1);
            board[row][c] = '.';
            col[c] = diag1[d1] = diag2[d2] = false;
        }
    }

public:
    vector<vector<string>> solveNQueens(int n) {
        this->n = n;
        col.assign(n, false);
        diag1.assign(2 * n - 1, false);
        diag2.assign(2 * n - 1, false);
        board.assign(n, string(n, '.'));
        ans.clear();

        dfs(0);
        return ans;
    }
};
```

- 时间复杂度：O(n!)，逐行放置皇后并剪掉冲突分支，最坏搜索规模不超过 n!
- 空间复杂度：O(n^2)，棋盘占 O(n^2)，列与对角线标记及递归栈占 O(n)
