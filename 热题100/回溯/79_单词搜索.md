# 79_单词搜索

## 题目

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**示例 1：**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
输出：true
```

**示例 2：**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
输出：true
```

**示例 3：**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
输出：false
```

**提示：**

- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

## 解法-深度优先搜索

枚举每个格子作为单词的起点，从该格开始向四个方向 DFS 匹配 `word` 的后续字符。搜索时把当前格子临时改成特殊字符，防止同一条路径重复使用同一个格子，回溯时再恢复；只要有一条路径能匹配完整个单词就返回 `true`。

```C++
class Solution {
    int m, n;

    bool dfs(vector<vector<char>>& board, const string& word,
             int r, int c, int k) {
        if (board[r][c] != word[k]) return false;
        if (k + 1 == (int)word.size()) return true;

        static const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        char original = board[r][c];
        board[r][c] = '#';

        for (const auto& d : dirs) {
            int nr = r + d[0], nc = c + d[1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
            if (dfs(board, word, nr, nc, k + 1)) {
                board[r][c] = original;
                return true;
            }
        }

        board[r][c] = original;
        return false;
    }

public:
    bool exist(vector<vector<char>>& board, string word) {
        m = board.size();
        n = board[0].size();

        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (dfs(board, word, i, j, 0)) {
                    return true;
                }
            }
        }
        return false;
    }
};
```

- 时间复杂度：O(m × n × 4^L)，其中 L 为单词长度；每个起点最多向四个方向搜索
- 空间复杂度：O(L)，递归栈深度最多为单词长度
