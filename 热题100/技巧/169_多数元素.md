# 169_多数元素

## 题目

给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：3
```

**示例 2：**

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

**提示：**

- n == nums.length
- 1 <= n <= 5 * 10^4
- -10^9 <= nums[i] <= 10^9

## 解法-Boyer-Moore 投票算法

维护一个候选元素 candidate 和它的票数 count。当前元素等于候选时票数加一，否则减一；票数减到 0 时换当前元素作为新候选。由于多数元素的出现次数超过一半，即使它与其它元素互相抵消，最终也一定会留下成为候选。

```C++
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int candidate = nums[0];
        int count = 0;

        for (int num : nums) {
            if (count == 0) {
                candidate = num;
            }
            count += (num == candidate) ? 1 : -1;
        }
        return candidate;
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)
