# 75_颜色分类

## 题目

给定一个包含红色、白色和蓝色、共 n 个元素的数组 nums ，原地 对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 0、 1 和 2 分别表示红色、白色和蓝色。

必须在不使用库内置的 sort 函数的情况下解决这个问题。

**示例 1：**

```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

**示例 2：**

```
输入：nums = [2,0,1]
输出：[0,1,2]
```

**提示：**

- n == nums.length
- 1 <= n <= 300
- nums[i] 为 0、1 或 2

## 解法-三指针（荷兰国旗问题）

用 low 指向 0 区域的下一个位置，high 指向 2 区域的前一个位置，i 从左向右扫描。遇到 0 就与 low 交换并同时右移 low 和 i，遇到 1 直接右移 i，遇到 2 就与 high 交换并左移 high（此时 i 不移动，因为换来的元素还未检查）。这样 0 被放到左边、2 被放到右边，扫描结束后中间自然全是 1。

```C++
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0;
        int i = 0;
        int high = nums.size() - 1;

        while (i <= high) {
            if (nums[i] == 0) {
                swap(nums[low], nums[i]);
                ++low;
                ++i;
            } else if (nums[i] == 1) {
                ++i;
            } else {
                swap(nums[i], nums[high]);
                --high;
            }
        }
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)
