# 53_最大子数组和

## 题目

给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

**示例 1：**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

**示例 2：**

```
输入：nums = [1]
输出：1
```

**示例 3：**

```
输入：nums = [5,4,-1,7,8]
输出：23
```

**提示：**

- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4

## 解法-动态规划（Kadane 算法）

设 f[i] 为以 nums[i] 结尾的最大子数组和，则 f[i] = max(f[i-1] + nums[i], nums[i])；因为任何以 nums[i] 结尾的连续子数组，要么接在以 nums[i-1] 结尾的最优子数组之后，要么从 nums[i] 重新开始，所以取二者较大值即为最优。答案取所有 f[i] 的最大值，用一个变量滚动即可。

```C++
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int pre = 0, ans = nums[0];
        for (int x : nums) {
            pre = max(pre + x, x);
            ans = max(ans, pre);
        }
        return ans;
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)
