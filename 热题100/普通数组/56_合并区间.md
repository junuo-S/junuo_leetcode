# 56_合并区间

## 题目

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

**示例 1：**

```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
```

**示例 2：**

```
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

**提示：**

- 1 <= intervals.length <= 10^4
- intervals[i].length == 2
- 0 <= starti <= endi <= 10^4

## 解法-排序后一次遍历

把所有区间按左端点升序排序，此时可以合并的区间在排序后必然相邻：若当前区间的左端点不大于结果中最后一个区间的右端点，两区间重叠或相接，直接更新右端点；否则说明出现新的不重叠区间，直接追加。这样每个区间只处理一次，结果恰好覆盖全部输入区间。

```C++
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> res;
        for (const auto& itv : intervals) {
            if (!res.empty() && itv[0] <= res.back()[1]) {
                res.back()[1] = max(res.back()[1], itv[1]);
            } else {
                res.push_back(itv);
            }
        }
        return res;
    }
};
```

- 时间复杂度：O(n log n)
- 空间复杂度：O(log n)
