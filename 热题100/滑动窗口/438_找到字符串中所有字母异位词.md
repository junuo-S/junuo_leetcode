# 438_找到字符串中所有字母异位词

## 题目

给定两个字符串 s 和 p，找到 s 中所有 p 的异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

异位词指由相同字母重排列形成的字符串（包括相同的字符串）。

**示例 1：**

```
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
解释：
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

**示例 2：**

```
输入：s = "abab", p = "ab"
输出：[0,1,2]
解释：
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

**提示：**

- 1 <= s.length, p.length <= 3 * 10^4
- s 和 p 仅包含小写字母

## 解法-定长滑动窗口

维护一个长度固定为 p.length() 的窗口，用两个大小为 26 的数组分别统计 p 和窗口内的字母频次。每次窗口右移一位只更新进出窗口的两个字符，频次数组相等时当前窗口就是一个字母异位词。

```C++
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int n = s.size(), m = p.size();
        if (n < m) {
            return {};
        }

        vector<int> need(26, 0), window(26, 0), ans;
        for (char c : p) {
            ++need[c - 'a'];
        }
        for (int i = 0; i < m; ++i) {
            ++window[s[i] - 'a'];
        }
        if (window == need) {
            ans.push_back(0);
        }

        for (int i = m; i < n; ++i) {
            ++window[s[i] - 'a'];
            --window[s[i - m] - 'a'];
            if (window == need) {
                ans.push_back(i - m + 1);
            }
        }
        return ans;
    }
};
```

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)
