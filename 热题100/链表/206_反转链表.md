# 206_反转链表

## 题目

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例 1：**

```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

**示例 2：**

```
输入：head = [1,2]
输出：[2,1]
```

**示例 3：**

```
输入：head = []
输出：[]
```

**提示：**

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

## 解法-迭代

用 `prev` 记录已经反转部分的头节点，依次让当前节点指回 `prev`，并用 `next` 暂存剩余链表。遍历结束时，`prev` 就是反转后链表的头节点。

```C++
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        while (head) {
            ListNode* next = head->next;
            head->next = prev;
            prev = head;
            head = next;
        }
        return prev;
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)
